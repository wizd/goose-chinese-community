:::info 仅桌面版
侧边栏自定义仅在 goose 桌面版中可用。
:::

侧边栏用于在 goose 桌面版的页面之间切换：主页、聊天、配方、应用、调度器、扩展和设置。你可以自定义它的外观、位置和行为，以配合自己的工作方式。

访问这些设置：

1. 点击左上角的 <PanelLeft className="inline" size={16} /> 按钮打开侧边栏
2. 在侧边栏中点击 `Settings`
3. 点击 `App` 选项卡
4. 滚动到 **导航** 部分

## 样式

选择侧边栏如何显示条目。

| 样式 | 说明 |
|-------|-------------|
| **磁贴**（默认） | 大图标配标签，以网格排列。适合快速扫视。 |
| **列表** | 紧凑的单列列表。占用空间更小，一次能显示更多条目。 |

:::note
在宽度小于 700px 的窗口中使用列表样式时，侧边栏会自动折叠为仅显示图标。
:::

## 位置

把侧边栏移到窗口的任意边缘。

| 位置 | 说明 |
|----------|-------------|
| **左侧**（默认） | 窗口左侧的垂直侧边栏 |
| **右侧** | 窗口右侧的垂直侧边栏 |
| **顶部** | 沿窗口顶部的水平栏 |
| **底部** | 沿窗口底部的水平栏 |

## 模式

控制侧边栏打开时内容如何变化。

| 模式 | 说明 |
|------|-------------|
| **推开**（默认） | 侧边栏占用空间，内容会挪开为它让位。工作时侧边栏保持可见。 |
| **覆盖** | 侧边栏浮在内容之上，不移动任何东西。点击外部或进行导航即可关闭。 |

:::note
在覆盖模式下，样式和位置设置不可用。侧边栏始终以全屏磁贴覆盖层出现。
:::

## 自定义条目

你可以在导航设置的 **自定义条目** 部分重新排序和隐藏侧边栏条目。

- **拖动条目**以调整顺序
- 点击**眼睛图标**以显示或隐藏单个条目

点击 `Reset to defaults` 可恢复原始顺序和可见性。

## 切换侧边栏

不必打开设置即可显示或隐藏侧边栏：

- **菜单栏：** 前往 **查看 → 切换导航**
- **键盘快捷键：** 快捷键显示在菜单项旁边，可在 `Settings` > `Keyboard` 中自定义

侧边栏的打开/关闭状态会在会话之间保留。
