goose Mobile 是一个受 goose 应用启发的实验性 Android 项目。它作为手机上的开放智能体，自动执行多步任务、响应通知，甚至可以替换主屏幕以获得更高效率。

:::danger 实验性
goose Mobile 需要深入访问你的设备。使用风险自负——最好在备用手机或模拟器上使用。
:::

## 它能做什么
- **自动化：** 使用你已安装的应用编排任务。
- **通知处理：** 根据你的规则响应收到的通知。
- **可扩展性：** 借助其他应用的扩展，无缝执行后台任务。


## 安装
- **预构建 APK：** 通过 [Firebase 分发链接](https://appdistribution.firebase.google.com/pub/i/3f111ea732d5f7f6) 快速安装。
- **从源码构建：** 开发者说明见 [goose Mobile 仓库](https://github.com/aaif-goose/goose-mobile)。


## 扩展 goose Mobile
goose Mobile 支持 **mobile MCP** 系统，可以在不离开当前上下文的情况下使用其他应用的工具——例如通过天气扩展获取天气数据。  

示例代码和设置说明见仓库 [README](https://github.com/aaif-goose/goose-mobile)。
