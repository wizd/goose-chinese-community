关键决策与最佳实践：

1. App Router 与 Pages Router：

选择 App Router，因为：
默认使用 Server Components（性能更好）
内置带流式传输的数据获取
用 Route Handlers 让 API 路由更简单
TypeScript 集成更好

2. 以 Prisma 作为 ORM：

优势：
类型安全的数据库查询
自动生成的客户端
Schema 迁移
丰富的查询 API
使用 Prisma Accelerate 以获得更好的性能

3. 身份验证：

选择 NextAuth.js，因为：
内置安全功能
多种身份验证提供商
会话管理
JWT 处理

4. 性能优化：

用 Server Components 减少 JavaScript
用 Route Handlers 做 API 端点
用 Prisma Accelerate 提升数据库性能
全栈类型安全
