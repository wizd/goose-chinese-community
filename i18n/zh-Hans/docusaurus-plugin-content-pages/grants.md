# goose 资助计划

我们设立了一项资助计划，以加速 goose 在开源社区中的发展。如果你相信智能体 AI 开放且人人可用的未来，欢迎与我们一起塑造这个未来。

    ##  → 申请 goose 资助
</Link>

<br/>
## 什么样的提案是好提案
<br/>

我们寻找清晰、有说服力且有野心的想法，并与 goose 的价值观一致：开放、模块化，以及增强用户能力。

我们很希望看到探索与 AI 智能体交互新方式的提案。下面只是几个例子：

- **新的交互范式：** 通过草图（白板！）、摄像头、关注情绪的语音交互，或其他多模态交互与 goose 互动
- **自驱动：** 通过增加长时间运行的后台模式、试验新的中间状态、深度规划，以及支持这种运行方式的工具，来提高自主性
- **自我改进的智能体：** Absolute Zero、Darwin Gödel Machine 和 AlphaEvolve 等工作展示了智能体如何改进自身。帮助 goose 改写它的系统提示、它的 MCP 服务器，也许还有它自己的代码
- **自动化一切：** 给 goose 与现实世界交互的工具，用于家庭自动化、机器人或 3D 打印。

最重要的是，我们希望资助与这些价值观一致、并体现出开源优先思维方式的工作。


<br/>
## 资助详情
<br/>

- **项目时长：** 12 个月
- **资助金额：** 每项资助 100,000 美元
- **结构：** 资助按里程碑发放，包含定期检查、交付物和付款

_受适用法律约束_

<br/>
## 常见问题
<br/>
**什么时候接受提案？**

我们滚动评审提案。没有固定截止日期，但更早提交会提高进入当前评审周期的机会。

**你们会接受多少份提案？**

在资源允许的范围内，我们会支持尽可能多与使命一致的优秀项目。

**12 个月后资助可以续期吗？**

有可能。我们可能根据进展、影响和一致性延长或续期资助。续期不作保证，将逐案评估。

**资助会带来 goose 或 AAIF 的工作机会吗？**

不会。资助不是雇佣，也不意味着未来会录用。不过，有影响力的工作可能会自然地发展出与 goose 或 AAIF 团队的合作。

**工作如何评审？**

每个资助项目都会定义明确的交付物和里程碑。进展由 goose 团队和选定的外部评审人按季度评审。

**付款如何安排？**

付款按里程碑、每季度发放，前提是进展更新令人满意。

**资助是否面向全球？**

是的。我们接受来自全球个人和团队的提案。付款以美元进行，但只要可行，我们会配合你的当地货币和付款偏好。

**我可以提出多个项目吗？**

可以。只要项目之间有显著差异，你可以提交多份申请。

**谁可以申请？**

任何人。我们欢迎独自工作或小团队协作的个人，只要这项工作尚未由雇主或客户资助，并受适用法律约束。有开源经验是加分项，但不是必需的。如果你热衷开源并有一个想法——哪怕只是草稿——我们鼓励你联系我们。
