goose 团队持续开发新功能的同时，超过 800 名社区成员投票表达了他们对 Windows 版 goose 的需求。今天的杰出贡献者正是为这项持续工作伸出了援手。

<!--truncate-->

## Windows 支持

自 codename goose 发布以来，开源社区一直希望并请求 goose 在 Windows 上提供同样的自动化能力。

目前，goose 的 CLI 版本可以通过 WSL（Windows Subsystem for Linux，Windows 的 Linux 子系统）在 Windows 上运行，但内置扩展支持有限。内部测试版也在推进中，但范围仍然有限，团队正在修复若干 bug 并做改进，好让 codename goose 在 Windows 上也能像在 Mac 上一样顺畅。

## ATrueLight4 的 Goose4Win

本期贡献者 [ATrueLight4](https://github.com/ATrueLight4) 交付了 **Goose4Win**，这项修复改进了 goose 处理 Windows 特有文件路径的方式。贡献已经合并进 main，所以如果你今天在 Windows 上安装 goose CLI，就会直接得到这项改进，无需额外配置。

非常感谢你的贡献，ATrueLight4！你的工作让我们离 Windows 版 goose 又近了一步。


为了表达我们深深的感谢，我们在 Block Open Source Discord 上授予你专属的 ✨Top Contributor✨ 徽章！你也会成为最早一批收到 codename goose 专属周边的贡献者之一。（更多消息稍后公布 👀🪿）

## 让你的贡献也上榜
有兴趣为 goose 做贡献，并让自己的工作被介绍出来吗？无论是改进平台支持、添加新功能，还是修复 bug，我们都欢迎开源社区的每一份贡献。你可以今天就[加入 Block Open Source Discord](https://discord.gg/n8R5VaWDAn)，或[开始使用 codename goose](https://goose-docs.ai/)。
