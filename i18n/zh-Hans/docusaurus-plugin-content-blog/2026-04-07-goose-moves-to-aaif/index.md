Block 已将 goose 捐赠给 Linux 基金会下的[智能体 AI 基金会（AAIF）](https://aaif.io/)，与 Anthropic 的模型上下文协议（MCP）以及 OpenAI 的 AGENTS.md 并列。你可以在[这里阅读完整公告](https://aaif.io/press/linux-foundation-announces-the-formation-of-the-agentic-ai-foundation-aaif-anchored-by-new-project-contributions-including-model-context-protocol-mcp-goose-and-agents-md/)。

goose 对使命和社区的投入没有变化，发生变化的是这些：

<!-- truncate -->

## 新的文档站点
文档已迁至新站点：[https://goose-docs.ai/](https://goose-docs.ai/)，用上了漂亮的 .ai 顶级域名！旧文档链接会重定向，请把书签更新到新站点。

## 更新后的 GitHub 仓库
GitHub 仓库及相关项目已从 `block/goose` 迁到一个新组织：

> **[https://github.com/aaif-goose/goose](https://github.com/aaif-goose/goose)**

这也包括 [aaif-goose](https://github.com/aaif-goose) 组织中的相关仓库。

其余一切——项目、社区、使命——都保持不变。goose 仍然开源，仍然在积极开发，仍然是你所熟悉的那个智能体。

## 更新你的远程地址

如果你有本地克隆，请更新 git remote：

```bash
git remote set-url origin git@github.com:aaif-goose/goose.git
```

## 迁移仍在进行

我们仍在处理一些迁移问题（失效链接、重定向、CI 等）。如果你遇到任何看起来不对的地方，请在 [Discord](https://discord.gg/n8R5VaWDAn) 上告诉我们。
## 了解更多

访问 [aaif.io](https://aaif.io/) 了解基金会及其使命。
