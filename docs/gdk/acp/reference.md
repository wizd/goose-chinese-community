# goose ACP Reference

The [ACP overview](/docs/gdk/acp) links here for methods that goose adds on top of
the standard [Agent Client Protocol](https://agentclientprotocol.com/). That
method list is not in the current upstream documentation.

Until it is published, use the overview for how to install and connect, and the
protocol site for the standard methods.
